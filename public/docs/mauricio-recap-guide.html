How to create & send a recap

A step-by-step walkthrough for Mauricio — from raw Placer data to a tracked send.

Log in

Open www.gorunrabbit.com/login and enter the Corner Bar Management password: cbm2026.

Once you’re signed in, go to Corner Bar Management → Feed The Block and click the Manage Recaps button at the top right.

Bookmark
The direct URL for recap management is /corner-bar-management/feed-the-block/recaps. Bookmark it.

Set up the artist

Each recap can link to an artist profile — the bio, hits, milestones, and social reach that appear in the Artist Spotlight section. You only need to add an artist once; they’re reusable across recaps.

  1. From the Recaps page, click Artists in the top right.
  2. Click + New Artist.
  3. Fill in: stage name, real name, born, nationality, years active, signature, bio.
  4. Add Notable Hits, Milestones, and Social Reach rows as needed.
  5. Click Create Artist.
Skip to later
If you don’t have artist details yet, you can create the recap first and wire the artist up later.

Create a new recap

On the Recaps page, click + New Recap.

Fill the four required fields:

  • Event ID — the URL slug, e.g. marshmello-apr2-2026. Use lowercase letters, numbers, and hyphens. This is permanent and becomes the public URL.
  • Headliner — display name, e.g. Marshmello.
  • Event Date — as you want it displayed, e.g. April 2, 2026.
  • Day of Week — e.g. Wednesday.

Then pick the artist from the Artist dropdown.

Enter Placer.ai data

The Placer data field is a single JSON object with eight arrays: metrics, hourly, duration, demographics, destinations, hotels, originStates, and originDMAs.

Fast way — clone a template

Above the JSON box, use the Clone structure from dropdown to pre-fill the full shape from a prior event (Marshmello, Diplo, Major Lazer). Then just edit the numbers.

Coverage checkboxes

Under the JSON box, check which data sections are present. If your Placer export is incomplete (PDF-only, say), uncheck the missing ones — the recap page will hide those sections instead of showing empty charts.

Sponsors

Click + Add Sponsor to add per-event sponsor rows. Each row needs a Name, Role (e.g. Founding Municipal Partner), and Category. Note is optional.

Click Create Draft at the bottom. You’ll land on the edit page for the new recap — photos live here.

Upload photos

Below the form on the edit page, scroll to the Photos section. Each slot expects one image:

  • Hero — the full-bleed image at the top of “The Event” section. Wide, impactful.
  • Polaroid — the tilted photo next to the artist name. Square framing works best.
  • Portrait — optional artist portrait.
  • Gallery — the “Night in Photographs” strip. Upload 3 photos (a 4:3 aspect looks best).
Slug tip
The slug is how the file is named on disk. Use descriptive hyphenated names like packed-crowd-hudson or artist-polaroid — lowercase, no spaces.
What happens server-side
When you upload, the server resizes the image to three widths (640px, 1280px, 1920px) and saves all three as optimized JPEGs. The recap page picks the right one for each placement automatically.

Preview the draft

On the edit page, click Preview Draft. The recap opens in a new tab with a Draft badge in the top right.

Only logged-in admins can see drafts — the public feed2026 gate does not grant access until you publish. Anyone else visiting a draft URL hits a 404.

Scroll through every section. Check the photo placements, the top-of-page stats (they’re computed from your Placer metrics array), and the Economic Impact figures.

Publish

Back on the edit page, click Publish. The status flips from yellow to cyan, and the recap becomes accessible at /recap/ftb-editorial/<event-id> behind the public feed2026 access code.

Unpublish anytime
If you need to pull a recap back, click Unpublish from the edit page. The link becomes unreachable to the public while you fix things, without losing any data.

Send it

From the Recaps list, click Send next to the row you just published (or use the Send action from the edit page header).

Paste the recipients

Paste into the text box, one recipient per line. Any of these formats works:

jane@example.com
Jane Doe <jane@example.com>
Jane Doe, jane@example.com

Optional — tag & save as a group

Add a group tag (e.g. LVCVA, Sponsors, Media) to mark this send. Then use Save Group to save the current list for future sends — it shows up under Saved Groups for one-click reuse.

Send

Click Send. You’ll be asked to confirm the count, then the results table appears below with one row per recipient.

What each recipient gets
An editorial-styled email from partnerships@feedtheblock.com with the recap’s headliner, date, and a View the Recap button linking to the published URL. Replies go back to you directly.

Track opens

Scroll to Send History on the same Send page. Each recipient row shows four timestamps: Sent, Delivered, Opened. Opens are populated by Resend’s tracking pixel.

Opens are best-effort
Many email clients (especially Apple Mail with privacy mode) block tracking pixels. Treat open counts as a floor, not a ceiling.

Make edits to a live recap

Every field on the Edit page stays editable after publishing. Edits are live immediately — no re-publish step needed.

If you need to pull a recap offline while you fix major things, click Unpublish, make the edits, then Publish again. The URL is the same throughout.

The recipient send history is preserved; past sends continue to work and track opens independently of edits you make later.

When something breaks

  • JSON error when saving — the Placer data textarea expects valid JSON. If you see a red error, check for a missing comma or bracket at the line number shown.
  • Photos don’t appear after upload — refresh the page. The upload writes to disk then updates the recap; occasionally the UI needs one refresh to pick up the new file.
  • Send button is greyed out — the recap is still in Draft. Publish it first.
  • Everything looks wrong — DM Keith. Don’t delete things in a panic; unpublish first, fix later.
